## Контекст
Подготовлен исследовательский порт XNU/iOS 16.5 на Xiaomi Redmi 9 (lancelot).
Дерево уже очищено к публикации: `tools/release-clean.sh --apply` снял с учёта
282 проприетарных/приватных файла (вендорские EFI QcomPkg, prebuilt-бинарники
включая бинарник ядра Apple, заголовки вендорских прошивок touchfw.h /
redwood_focaltech_fw.h, 26 скриншотов iOS в docs). Приватные данные (серийники,
BD_ADDR, пароли, handoff) удалены/исключены. Изменения **застейджены, но не
закоммичены**. Текущий репозиторий — shallow и содержит проприетарные блобы в
истории, поэтому публиковать нужно **свежий экспорт без старой истории**.

## Задача (выполни по шагам, ничего не публикуй без подтверждения)
1. **Проверь чистоту индекса**:
   `git grep --cached -nI -E '<BD_ADDR>|<device serial>|BEGIN PRIVATE'`
   (подставь свои маркеры) — должно быть пусто. `git ls-files --cached | grep -i handoff` — пусто.
   Убедись, что `docs/handoff-gpt-bluetooth.md`, `logs/`, локальные
   `tools/.*.sh` не отслеживаются.
2. **Создай свежую публикацию без проприетарной истории** (один из вариантов):
   - новый orphan-бранч: `git checkout --orphan publish`, `git add -A` (учитывая
     .gitignore и exclude), `git commit -m "HakiOS: XNU/iOS 16.5 on Redmi 9 (lancelot) — research port"`;
   - либо новый репозиторий из очищенного дерева (`git archive` индекса → новая
     папка → `git init` → commit).
   Не пушь старый shallow-репозиторий с историей.
3. **Финальный аудит опубликованного дерева**: нет бинарников Apple/вендора
   (`*.efi`, `*.bin`, `*.img`, `*.apfs`, `*.dtb`, `*.fd`, prebuilt/,
   touchfw.h, focaltech_fw.h), нет скриншотов iOS (`docs/*.jpg|png`), нет
   приватных данных. Есть исходники драйверов, патч XNU, docs, скрипты сборки.
4. **Создай GitHub-репозиторий** (например `hakios-lancelot`) и запушь
   publication-бранч. Добавь описание и темы (xnu, ios, mediatek, redmi9,
   research).LICENSE: APSL-2.0 для патча XNU, MIT для остального (см. README).
5. **Обнови пост для 4PDA** `docs/4pda-post.md`: подставь ссылку на репозиторий.
   Пост уже написан (честно: что работает, что нет). Не приукрашивай статус.
6. **Не делай** автоматических релизов/тегов без подтверждения; не публикуй
   проприетарные ассеты; не форкай Apple-репозитории с бинарниками.

## Что публиковать можно
- `xnu/redwood.patch`, `xnu/files/` (драйверы порта, MIT/APSL), `xnu-src/`
   **не** публиковать (это внешнее дерево Apple XNU, собирается пользователем).
- `mtkloader/` (без touchfw.h), `userland/` (исходники, без fw/network),
   `tools/` (без локальных dot-скриптов), `docs/` (без скриншотов),
   `ios165/` (только скрипты fetch/select), `wifi/`, `xnuloader/`, README.

## Проверка после публикации
- `git ls-files` опубликованного репо не содержит проприетарных блобов.
- README ведёт на `docs/from-a-clone.md` (сборка из своего IPSW).
- Пост 4PDA ссылается на репо и честно описывает статус.
